# BriefMint recording checklist

## Before capture

- [ ] Confirm the already saved genuine generated draft, edited revision, approval, Arkiv receipt/entity, and sanitized independent-read evidence are available.
- [ ] Use the local UI at `http://127.0.0.1:3001`; do not imply it is publicly hosted.
- [ ] Do not trigger inference, wallet signatures, create/update/close, or any new write. Do not retry the unresolved R3 intent.
- [ ] Hide private source notes, credentials, environment files, cookies, wallet signature details, and unrelated tabs/notifications.
- [ ] Check on-screen owner, entity and transaction values against [live evidence](../evidence/LIVE_DEMO.md).
- [ ] Set readable zoom and capture clear UI text and any pre-existing CLI output.
- [ ] Use the demo guide’s truthful backup if the RPC is unavailable. Label saved evidence with its original capture time.

## Required coverage

- [ ] Product and problem in one sentence.
- [ ] Saved genuine 0G-generated, editable draft; say it is a saved result and do not claim independent TEE verification.
- [ ] Owner-edited public projection and approval/hash boundary.
- [ ] Actual Arkiv receipt/entity and checked public record identifiers.
- [ ] Independent CLI read path, or clearly stated endpoint outage with timestamped saved evidence.
- [ ] Disclose that source data is backend-access-controlled, not end-to-end encrypted.
- [ ] Disclose unresolved original intent and distinct demo copy/duplicate-content risk.
- [ ] State limits: no live update/close/expiry, independent TEE verification, hosting, applicants, escrow, or payments established.
- [ ] End by 2:30; absolute maximum is 2:59.

## After capture

- [ ] Review the full video for accidental private data, wallet prompts, hidden secrets, misleading “live” edits, and illegible evidence.
- [ ] Confirm duration is under 3 minutes and audio is intelligible.
- [ ] Add the video URL to the submission only after upload and playback verification: `[ADD VERIFIED VIDEO URL]`.
- [ ] Add a public demo URL only if one is actually deployed and checked: `[ADD VERIFIED DEMO URL]`.
- [ ] Keep attribution/license status accurate; the audit is incomplete.
