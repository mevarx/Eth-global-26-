# BriefMint design system

Source of truth: `src/styles/briefmint-tokens.css` (tokens, glass, buttons, chips, inputs, cards), `src/styles/typography.css` (type utilities), `src/lib/ui/fonts.ts` (next/font). All components use `--bm-*` tokens; no hard-coded component colors or sizes.

## Fonts
Self-hosted at build via `next/font/google`, `display: "swap"`, latin subset. No runtime CDN links.

| Role | Font | Weights | Variable → token |
|---|---|---|---|
| Body | Inter | 400, 500, 600 | `--font-inter` → `--bm-font-body` |
| Headings, wordmark | Space Grotesk | 500, 600, 700 | `--font-space-grotesk` → `--bm-font-heading` |
| Mono | JetBrains Mono | 400, 500 | `--font-jetbrains-mono` → `--bm-font-mono` |

Mono is only for addresses, keys, hashes, counters and tiny status tags. Every token stack ends in system fallbacks, so the UI stays readable if a font fails to load.

## Type scale
| Token | Size | Use |
|---|---|---|
| `--bm-text-xs` | 12px | Minimum anywhere (chips, labels, tags, scene/HUD, tooltips) |
| `--bm-text-sm` | 13px | Secondary text, buttons |
| `--bm-text-md` | 15px | Body (line-height `--bm-leading` 1.55) |
| `--bm-text-lg` | 17px | Panel titles (`.bm-title-panel`) |
| `--bm-text-page` | 32px (28px under 480px) | Page titles (`.bm-title-page`) |

Sentence case for paragraphs, titles and buttons. ALL CAPS only via `.bm-tag` (12px, letter-spacing 0.08em). Use `.bm-num` for counters (tabular numbers) and `.bm-measure` (70ch) on paragraphs. Utility classes: `.bm-title-page`, `.bm-title-panel`, `.bm-secondary`, `.bm-muted`, `.bm-tag`, `.bm-mono`, `.bm-num`, `.bm-measure`, `.bm-sr-only`.

## Colors
Dark chrome: `bg-0 #060f1a`, `bg-1 #0b1b2e`, `bg-2 #10263d`, `line rgba(169,187,207,.22)` (decorative dividers only), `line-strong #6f87a1` (borders and icon outlines that must reach 3:1).
Text: primary `#f1f5f9`, secondary `#b4c3d4`, muted `#93a6bb` (large or non-essential text only).
Accent amber `#f5b02e` (text on it: `--bm-on-accent #0b1b2e`), teal `#2dd4bf`, success `#4ade80`, warning `#fbbf24`, danger `#f87171`, info `#60a5fa`.
State is never conveyed by color alone: pair every chip/status with an icon and text.

## Spacing, radii, touch, focus
Spacing `--bm-space-1..6` = 4, 8, 12, 16, 24, 32px. Radii `--bm-radius-sm/md/lg` = 8/12/16px (chips are pills). Interactive controls are at least `--bm-touch` (40px) tall. Focus: `--bm-focus-ring` (2px solid amber) with `--bm-focus-offset` 2px, applied on `:focus-visible` for `.bm-btn`, `.bm-input`, `.bm-card` and `.bm-focusable`.

## Components
- **Button** `.bm-btn`: 40px min height, 8px radius, 13px/600 Inter, `bg-2` fill, `line-strong` border. `.bm-btn--primary`: amber fill, `--bm-on-accent` text. `.bm-btn--ghost`: transparent. Disabled: 55% opacity, `not-allowed`. Sentence-case labels.
- **Chip** `.bm-chip` + `--ok|--warn|--danger|--info|--muted`: 12px/600, pill, tinted solid background, tone-colored text and border, optional 14px icon (always include icon + text).
- **Input** `.bm-input`: 40px min height, `bg-0` fill, `line-strong` border, 15px body text, placeholder `text-muted`; `aria-invalid="true"` switches to a danger border (add an error message with icon, not color alone).
- **Card** `.bm-card`: `bg-1` fill, `--bm-line` border, 12px radius, 16px padding; `.bm-card--selected` adds an amber border (also expose selection via `aria-pressed`/`aria-selected` and a visible label).
- **Glass** `.bm-glass`: reference `.gw-glass` recipe (backdrop blur + saturate, inset top highlight × edge, inset border highlight, outer shadow, `::before` tint at 0.12, solid `@supports not` fallback). The look is FIXED at the reference "Frosted" preset via `--bm-glass-*` tokens (no adjustable glass provider; `briefmint.glass.v1` localStorage keys are ignored). Fixed values: blur 22px, opacity 0.7, saturation 1.2, edge 0.6, navy surface (`bg-1`), white highlight, tint `#7aa7d6`. `.bm-glass--text` adds a 35% navy underlay for text-heavy panels over busy backgrounds.

## Dashboard sky
`--bm-sky-top #1f5fa8`, `--bm-sky-bottom #7ec0ee`, `--bm-cloud #f4f7fb`, `--bm-scrim rgba(6,15,26,.38)` feed the cloud shader. Text on the sky must sit on `.bm-glass--text` panels or the scrim.

## Scene palette
`--bm-scene-*` colors (grass, grass-dark, sand, water, water-deep, foliage, foliage-dark, trunk, wood, roof-red, roof-blue, wall-light, wall-shade, stone, path, window, lamp-glow, solar-panel, court, crate, ink, sign, sign-ink, plate, plate-edge) are for original SVG overlay art only, matched to the Pixi island constants in `city-engine.ts`. Not for UI chrome.

## Wiring
In `src/app/layout.tsx`: `import { fontVariables } from "@/lib/ui/fonts";`, `import "@/styles/briefmint-tokens.css";`, `import "@/styles/typography.css";` (before `./globals.css`), and `<html lang="en" className={fontVariables}>`. The `@fontsource` imports can then be removed; `globals.css` font variables (`--font-hud`, `--font-body`, `--font-mono`) should be remapped to `--bm-font-*` by SA-12, and the Pixi engine still names `'Space Mono'` for canvas text (no longer loaded, falls back to monospace until changed).
